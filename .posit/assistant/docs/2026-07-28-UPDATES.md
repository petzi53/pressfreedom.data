## R Code Changes

### `R/clean.R`

#### `clean_period_1()` — Added year_n inference for 2012

**Change:** Lines 72–77
```r
# Handle year_n for 2012: raw data contains "2011-12" which converts to NA
# Fill with year parameter when all values are NA
if (all(is.na(df$year_n))) {
  df <- df |>
    dplyr::mutate(year_n = year)
}
```

**Rationale:** Raw 2012 file contains "2011-12" (text) → converts to NA during numeric conversion. Now handled directly in cleaner instead of requiring correction during Phase C.

**Documentation:** Updated roxygen comments (line 18) to mention this special case.

---

#### `clean_period_3()` — Added decimal conversion for score_evolution

**Change 1:** Updated roxygen comments (line 167)
```r
#' 7. Apply decimal separator conversion to all numeric columns (handles score_evolution)
```

**Change 2:** Lines 202, 207–213
```r
# Include "score_evolution" in numeric_target_cols list
numeric_target_cols <- c(
  "year_n", "score", "rank", "rank_n_1", "score_n_1", "rank_evolution",
  "political_context", "rank_pol", "economic_context", "rank_eco",
  "legal_context", "rank_leg", "social_context", "rank_soc",
  "safety", "rank_saf", "score_evolution"  # ← Added
)

# Apply decimal conversion within mutate/across
df <- df |>
  dplyr::mutate(
    dplyr::across(
      dplyr::all_of(numeric_to_convert),
      # Handles comma decimals in score_evolution (2023+ data)
      ~suppressWarnings(as.numeric(stringr::str_replace_all(as.character(.), ",", ".")))
    )
  )
```

**Rationale:** Period 3 (2023+) contains "score_evolution" with comma decimals (e.g., "2,53"). Previous code didn't apply decimal conversion to this column, resulting in character type. Now converted within the Phase B cleaner.

**Impact:** Eliminates need for post-hoc decimal conversion during Phase C combination.
