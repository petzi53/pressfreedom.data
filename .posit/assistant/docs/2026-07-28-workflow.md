# pressfreedom.data — Complete Workflow

**Date:** July 28, 2026  
**Project:** pressfreedom.data R Package  
**Objective:** Download, clean, normalize, and standardize press freedom data from Reporters Sans Frontières (RSF)

---

## Workflow Overview

```
Phase A: Download
  ↓
Phase B: Column Normalization
  ↓
Phase C: Data Combination
  ↓
Phase D: Country Standardization
```

---

## Phase A: Download

**Status:** Complete

**Function:** `download_rwb_data(years, output_dir)`

**Output:** Raw CSV files in `data/raw/`
- `rwb2002.csv` through `rwb2026.csv` (excluding 2011)
- 24 files total
- Original format preserved for auditability

---

## Phase B: Column Normalization

**Status:** Complete

**Input:** Raw CSV files from `data/raw/`

**Output:** Normalized RDS files in `data/cleaned/period_X/`
- `period_1/`: 11 files (2002–2012)
- `period_2/`: 9 files (2013–2021)
- `period_3/`: 5 files (2022–2026)

**Functions:**
- `clean_period_1(filepath, year)` — Normalize Period 1 data
- `clean_period_2(filepath, year)` — Normalize Period 2 data
- `clean_period_3(filepath, year)` — Normalize Period 3 data
- `clean_rwb_single(filepath, year, output_dir)` — Dispatcher
- `clean_all_rwb_years(input_dir, output_dir)` — Batch processor

**Key Transformations:**
- Normalize column names to 20-column unified structure
- Convert data types (factors → character for iso, country_en, zone)
- Handle decimal separators (comma → period)
- Add NA columns for unavailable data (dimensions in Periods 1–2)
- Handle special cases (2012 year_n, 2025–2026 score naming, 2024 Situation column)

**Output:** All files have identical 20-column structure:
```
year_n, iso, country_en, score, rank,
political_context, rank_pol, economic_context, rank_eco,
legal_context, rank_leg, social_context, rank_soc,
safety, rank_saf, zone, rank_n_1, rank_evolution,
score_n_1, score_evolution
```

---

## Phase C: Data Combination

**Status:** Complete

**Input:** 25 RDS files from `data/cleaned/period_X/`

**Output:** Single combined file `data/processed/rwb_combined.rds`

**Function:** `combine_cleaned_periods(input_dir, output_file)`

**Specifications:**
- 4,200 rows (180–207 countries × 24 years)
- 20 columns (unified structure)
- ~74 KB file size
- Sorted by year_n, then country_en

**Purpose:** Merge all periods into single dataset before standardization (simpler logic, single pass)

---

## Phase D: Country Standardization

**Status:** Not yet started

**Input:** `data/processed/rwb_combined.rds`

**Output:** `data/processed/rwb_standardized.rds`

**Tasks:**

## Key Features

### Auditability
- Raw files preserved unchanged
- Period separation maintained (can trace any row back to original period)
- All transformations logged at each phase
- Reproducible from raw CSV to final output

### Consistency
- All files follow same 20-column structure after Phase B
- Data types consistent within columns
- Missing values documented and intentional (NA for unavailable data)

### Maintainability
- Single standardization function in Phase D (not per-period)
- Clear phase boundaries with intermediate outputs
- Centralized column mapping configuration
- Comprehensive test coverage

### Flexibility
- Early combination allows single standardization pass
- Period information preserved in year_n column
- Easy to filter by period or year for analysis
